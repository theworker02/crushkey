# crushkey

Crush and reshape key text streams with deterministic transforms.

**Site:** https://theworker02.github.io/crushkey/

## Install / run

```bash
git clone https://github.com/theworker02/crushkey.git
cd crushkey
node src/cli.js
node --test
```
